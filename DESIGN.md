# Energy Dashboard — Load Room

## Visual world

A quiet control room after dark: the load curve is the instrument, cyan is the live trace, amber is the operator's marker, and the panel never pretends to be a utility bill.

## System

- Palette: navy `#102333`, deep navy `#0a1721`, paper `#edf0e8`, cyan `#88d6d1`, amber `#f0b966`, green `#9fca8b`, red `#ea775f`.
- Type: Georgia for the reading thesis; Courier New for signal labels, timestamps, and units.
- Composition: time-window rail → curve panel and site list → operator readout.
- Signature interaction: changing the time window reshapes the curve; choosing a site updates the readout while preserving the curve context.
- Responsive rule: curve stays first, sites follow, and readout becomes a vertical instrument strip.

## Integrity

Every value is synthetic and the no-meter boundary is visible in the control rail and footer.
